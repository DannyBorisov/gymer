# Gymerr - Codebase Guide

Workout tracking app using Google Sheets as a database.

## Tech Stack

### Backend (`packages/backend/`)
- **Fastify** 5.x - Web framework with plugin architecture
- **Google APIs** - Sheets & Drive for data storage
- **TypeScript** - Strict mode enabled

### Frontend (`packages/frontend/`)
- **React** 18 + TypeScript
- **React Router** 7 - Routing
- **Recharts** - Charts/visualization
- **Capacitor** - iOS native bridge
- **Lucide React** - Icons

## Backend Architecture

### Directory Structure
```
backend/src/
├── app.ts              # Fastify app setup
├── server.ts           # Entry point
├── types.ts            # Shared TypeScript interfaces
├── routes/             # Route definitions (FastifyPluginAsync)
│   └── index.ts        # Route aggregator with prefixes
├── handlers/           # Route handler logic (RouteHandler functions)
├── middlewares/
│   └── auth.ts         # requireAuth middleware, getAuthSession()
├── lib/                # Shared utilities
└── plugins/
    └── googleSheets.ts # Google Sheets plugin (this.sheets)
```

### Route Pattern
```typescript
// routes/myfeature.ts
import type { FastifyPluginAsync } from "fastify";
import { requireAuth } from "../middlewares/auth.js";
import { myHandler } from "../handlers/myfeature.js";

export const myRoutes: FastifyPluginAsync = async (server) => {
  server.get("/endpoint", { preHandler: requireAuth }, myHandler);
};

// Register in routes/index.ts:
server.register(myRoutes, { prefix: "/my-feature" });
```

### Handler Pattern
```typescript
// handlers/myfeature.ts
import type { RouteHandler } from "fastify";
import { getAuthSession } from "../middlewares/auth.js";

export const myHandler: RouteHandler<{ Body: MyRequestType }> = async function (
  request,
  reply,
) {
  const { tokens } = getAuthSession(request);
  // Use this.sheets for Google Sheets operations
  // Use this.log for logging
  return { success: true };
};
```

### API Routes
- `POST /api/program/create` - Create program
- `GET /api/programs` - List programs
- `GET /api/programs/:id` - Program detail with weeks/workouts
- `PATCH /api/programs/:id/rows` - Update exercise data
- `POST /api/quick-workouts` - Create/get quick workout sheet
- `GET /api/quick-workouts/exercises` - Get all exercises
- `POST /api/quick-workouts/save` - Save quick workout
- `GET /api/workouts/history` - Workout history
- `GET /api/body-weight` - Fetch weight entries
- `POST /api/body-weight` - Save weight entry
- `GET /api/analytics/progression` - Exercise progression data

### Data Fetching Pattern
```typescript
import { apiFetch } from "../../utils/api";

const fetchData = async () => {
  const response = await apiFetch("/api/endpoint");
  const data = await response.json();
  if (response.ok) {
    setData(data);
  }
};
```

### Program Sheet Columns (A-L)
Date | Week | Workout | Exercise | Set | Target Reps | RIR | Weight | Reps Achieved | RIR Achieved | Notes | Duration

### Quick Workouts Sheet Columns (A-I)
Date | WorkoutId | Exercise | Set | Weight | Reps | RIR | Notes | Duration

### Body Weight Sheet Columns (A-B)
Date | Weight

## Conventions
- **Date format**: DD/MM/YYYY
- **Duration format**: HH:MM:SS
- **Auth**: OAuth 2.0 with Google (cookies for web, Bearer token for native)
- All handlers require `requireAuth` preHandler for protected routes
- Use `buildQuery()` from googleSheets plugin to query files by app properties
